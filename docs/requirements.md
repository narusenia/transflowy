# transflowy 要件定義

録音・文字起こし・要約のデスクトップアプリ（Plaud 的）。UX を最優先する。

## 要検証（PoC）

実装前に確認する。結果次第で該当の決定を見直す。

| # | 項目 | 影響する決定 |
|---|---|---|
| P1 | OpenRouter `/api/v1/audio/transcriptions` の制約（処理タイムアウト 60 秒説、ファイルサイズ上限、MAI-Transcribe-2 の diarization オプションの渡し方） | チャンク長、話者分離（クラウド） |
| P2 | whisper.cpp `whisper-server` をサイドカー起動し、large-v3-turbo で日本語 + 英語混在音声の精度・速度を確認 | ローカル ASR |
| P3 | sherpa-onnx Go バインディングで VAD（silero）と話者分離が mac / Windows で動くか | VAD、話者分離（ローカル） |
| P4 | malgo で 16kHz モノラル録音、macOS のマイク権限ダイアログが出るか（固定署名下） | 録音 |
| P5 | `afconvert` で m4a / mp3 / wav / aac / caf を 16kHz WAV にデコードできるか、動画（mp4 / mov）は可能か | 取り込み、保存形式 |
| P6 | WebView の `<audio>` で保存フォルダ内の m4a を再生する方法（mygo のファイル配信手段） | 再生 |

## 前提

- 利用者: 自分個人（A）。業務利用（B: 社内会議・商談・面接）に耐える設計にする
- 業務利用では会社データを契約外の外部サービスに送れない → 「ローカル限定」トグルで保証する
- 対象 OS: macOS（Apple Silicon）が第一。Windows はビルド可能な状態を維持し、OS 依存部は `_darwin.go` / `_windows.go` で分ける
- 最低 macOS: 14.2（Core Audio Tap のため。2 段目で必要）
- 言語: 日本語主体 + 英語混在。自動言語判定、録音ごとに上書き可
- UI 言語: 日本語のみ

## 技術構成

| 層 | 採用 |
|---|---|
| アプリ基盤 | mygo（Go + WebView）。identifier `one.nxeu.transflowy` |
| UI | Web ページ。React + Tailwind + shadcn/ui、cmdk / sonner / TanStack Virtual / wavesurfer.js。アニメーションは CSS 主体 |
| 録音 | Go 側で malgo（miniaudio）。窓が閉じていても録音できる |
| VAD | sherpa-onnx（silero VAD） |
| 文字起こし（クラウド） | OpenRouter `microsoft/mai-transcribe-2` |
| 文字起こし（ローカル） | whisper.cpp `whisper-server` を同梱しサイドカー起動。モデル large-v3-turbo（q5_0 量子化、約 0.6GB）を初回 DL |
| 文字起こし（その他） | 任意の OpenAI 互換 URL（`/audio/transcriptions`） |
| 話者分離 | クラウド: MAI-Transcribe-2 の diarization。ローカル: sherpa-onnx |
| 要約 | OpenRouter、または OpenAI 互換 URL（Ollama / LM Studio 等。Ollama は自動検出） |
| 音声変換 | macOS 標準 `afconvert`。Windows は実装時に再判断 |
| 秘密情報 | OS キーチェーン（mygo の `mygo.Secrets`）。画面ではマスク表示のみ |

文字起こしと要約のプロバイダは個別に選ぶ。

## 機能要件

凡例: **MVP** = 最初のリリース、**2** = 2 段目。

### 録音・取り込み

| 段 | 要件 |
|---|---|
| MVP | マイク録音 |
| MVP | ファイル取り込み（m4a / mp3 / wav / aac / caf）。窓 / Dock アイコンへのドロップ |
| MVP | 録音中は 16kHz モノラル PCM を数秒ごとにディスクへ追記（クラッシュしても直前まで残る） |
| MVP | 停止後に m4a（AAC）へ変換して保存 |
| 2 | システム音声録音（mac: Core Audio Tap / Win: WASAPI loopback）。マイクと別トラックで保存 |
| MVP | 動画ファイル取り込み（mp4 / mov。`afconvert` で音声を抽出できると P5 で確認済み） |

### 録音の導線

| 段 | 要件 |
|---|---|
| MVP | メイン窓の録音ボタン |
| MVP | グローバルショートカット（既定 `⌥⌘R`）で開始 / 停止 |
| MVP | メニューバーアイコン。クリックで開始 / 停止、録音中は経過時間を表示 |
| MVP | 停止直後 5 秒間「取り消し」トースト |
| 2 | 会議自動検出（他アプリのマイク使用開始 → 通知で録音を提案） |
| 2 | 録音中ミニ HUD（メニューバー表示で足りなければ） |

### 文字起こし

| 段 | 要件 |
|---|---|
| MVP | 録音後一括方式。ただし録音中に VAD で無音区間ごとにチャンク化（最大 15 秒）し、チャンクごとに言語を自動判定しながら裏で先行処理して、停止後の待ちをほぼゼロにする。1 チャンクに複数言語を混ぜると片方が落ちるため（P2） |
| MVP | 固有名詞辞書。MAI → phraseList、Whisper → initial prompt に渡す |
| MVP | データは最初から `speaker` フィールドを持つ（MVP では未使用） |
| 2 | 話者分離と話者名の付け替え（「話者 1 → 田中」）。別トラック録音時はマイク側を「自分」に確定 |
| 2 | ライブ字幕（チャンク結果を録音中に逐次表示） |

### 要約

| 段 | 要件 |
|---|---|
| MVP | テンプレート選択式（議事録 / 1on1 / 商談 / 面接 / 講義 / 汎用メモ）。既定テンプレートで自動実行 |
| MVP | ユーザー作成テンプレート（Markdown + frontmatter のファイル） |
| MVP | 別テンプレートで再生成、複数の要約を保持 |
| MVP | 要約内の `[12:34]` をクリックすると文字起こしの該当行へ移動して再生 |
| MVP | タイトル自動生成（要約と同時）。編集可。未処理時は日時 |
| 2 | テンプレート自動選択 |
| 2 | 録音内容への質問チャット |

### 文字起こしの編集

| 段 | 要件 |
|---|---|
| MVP | セグメント単位のインライン編集。元の認識結果は `original` に残し、元に戻せる |
| MVP | 一括置換。置換時に「辞書に追加しますか？」を提案 |
| MVP | 文字起こしが要約より新しい場合に「再生成」バッジ。再生成は手動 |

### 画面

| 段 | 要件 |
|---|---|
| MVP | 2 ペイン: 左に録音一覧（日付グループ）、右に詳細 |
| MVP | 詳細は要約と文字起こしを左右に分割。幅 1100px 未満ではタブ切替 |
| MVP | 下部に常駐プレーヤー（速度 1〜2x）。再生位置の行をハイライトし自動追従 |
| MVP | `⌘\` でサイドバー折りたたみ |
| MVP | `⌘K` でタイトル・文字起こし・要約を横断検索 |
| 2 | 無音スキップ再生 |

### 書き出し

| 段 | 要件 |
|---|---|
| MVP | クリップボードへ Markdown コピー（要約のみ / 要約 + 文字起こし / タイムスタンプ有無を選択） |
| MVP | .md / .txt / .srt 書き出し |

外部サービス連携（Notion / Slack 等）は行わない。保存先を Obsidian Vault 配下にすれば Obsidian 連携は追加実装なしで成立する。

### 処理キューと失敗

| 段 | 要件 |
|---|---|
| MVP | 処理はキュー方式。失敗したチャンクだけ指数バックオフで自動リトライ |
| MVP | オフライン時は待機し、復帰後に自動再開 |
| MVP | 一覧に状態バッジ（録音中 / 処理中 n% / 要約待ち / 失敗） |
| MVP | 窓が背面のとき、処理完了を通知 |
| MVP | 失敗バッジから「ローカルで処理」をワンクリック。自動フォールバックはしない |

### プロバイダ切替とローカル限定

| 段 | 要件 |
|---|---|
| MVP | 全体の既定プロバイダ + 録音ごとの「再処理」でエンジン変更 |
| MVP | 「ローカル限定」トグル。ON の間はクラウド送信（文字起こし・要約とも）を 1 か所のガードで全面禁止し、メニューバーアイコンに鍵マークを出す |
| 2 | 保存先がクラウド同期フォルダ（iCloud / Dropbox 等）のとき、ローカル限定 ON 中は警告 |

### 初回起動

| 段 | 要件 |
|---|---|
| MVP | 3 ステップ: ① マイク権限 ② エンジン選択（OpenRouter キー入力 / ローカルモデル DL 開始） ③ ショートカット確認 |
| MVP | モデル DL は裏で進め、オンボーディングは先へ進める |
| MVP | キー未設定・モデル未 DL でも録音は常に可能。処理は準備ができ次第自動で始める |
| MVP | クラウド選択時のみ、10 秒の試し録音で結果を即表示 |

## データ保存

ファイル主体。録音 1 件 = 1 フォルダ。既定の保存先は `~/Documents/Transflowy/`、ユーザーが変更できる。

```
~/Documents/Transflowy/
  2026-10-20_1030_週次定例/
    audio.m4a          # 2 段目の別トラック時は mic.m4a / system.m4a
    transcript.json    # セグメント: start, end, speaker, text, original
    summary-議事録.md
    summary-汎用メモ.md
    meta.json          # タイトル、言語、使用エンジン、状態
  templates/
    議事録.md
  dictionary.txt
```

- 検索は起動時に読み込んでメモリ上で走査する。千件を超えて遅くなったら SQLite FTS を索引として足す
- 音声は AAC 32kbps モノラル（1 時間で約 14MB）

## 配布

- MVP: 自分の Mac でビルドして使う。権限がビルドごとにリセットされないよう、固定の自己署名証明書で署名する
- 公開時: GitHub Releases + Developer ID 署名・公証 + mygo 自動更新。whisper-server サイドカーも署名対象
- Mac App Store は対象外（サンドボックスがサイドカー起動・任意フォルダ保存と衝突する）
